# Neon Drift: Cyber Odyssey

A neon sci-fi arcade survival game. Single file, no assets, no dependencies.

## Run
Open `index.html` in any modern browser (or paste it into a Claude Artifact).

## Controls
| Input | Action |
|---|---|
| WASD / Arrow keys | Thrust (acceleration + friction) |
| Mouse | Aim / ship orientation |
| Space (or click) | Dash: invincible, smashes rocks and seekers, 1.9s cooldown |
| P / Esc | Pause |
| M | Mute |
| R | Restart (also click or Enter on Game Over) |

## Gameplay
- Collect yellow energy cores; chain them within 3s for up to x5 combo.
- Red rocks drift in, orange seekers hunt you after ~14s, purple spinning blades appear after ~28s.
- Dash through rocks and seekers for bonus points.
- Green + packs restore hull. Difficulty ramps with time.
- High score is saved in localStorage.
